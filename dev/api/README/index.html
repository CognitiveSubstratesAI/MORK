MORK API Reference

Complete index of exported symbols from MORK.jl.

For prose guides see docs/guide/:

  • expressions.md — byte-encoding layout
  • space_rules.md — writing rules + the calculus
  • sinks.md — output combinators (+, -, fsum, count, ...)
  • server.md — HTTP server surface
  • zipper_queries.md — direct PathMap zipper-algebra queries (use when you want reads / traversals over an existing trie without the rule engine; works polymorphically over .act mmap'd snapshots)

The trie substrate lives in a separate package: PathMap.jl — byte-keyed, prefix-compressed, structurally-shared trie with first-class zipper algebra and .act mmap serialization. See its docs/guide/ for the substrate API.
