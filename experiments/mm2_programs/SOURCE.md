# Source attribution

The `.mm2` programs under `programs/` are copied from the **MM2_Structuring_Code** tutorial by
**Clarke Remy** — <https://github.com/ClarkeRemy/MM2_Structuring_Code> (folder
`structuring_code/mm2_programs/`).

They are included here **unmodified, for differential/robustness testing** of the Julia MORK
port against canonical MM2 programs (predication, sources/sinks, control flow, recursion,
fork/join, macros) that the small `main.rs` unit tests don't exercise. All credit to the
original author; see the upstream repo for the accompanying tutorial text and licensing.
